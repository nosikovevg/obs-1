## Полная сигнатура функции torch.tensor()

Если посмотреть на функцию шире, у нее есть несколько важных именованных аргументов. Если вы их называете, порядок не важен:

python

```
torch.tensor(data, dtype=None, device=None, requires_grad=False)
```

Используйте код с осторожностью.

- **`dtype`** (тип данных) — например, `torch.float64` или `torch.int32`. Если пропустить, PyTorch догадается сам по типу входящих данных.
- **`device`** (устройство) — где выделить память под тензор: на процессоре (`'cpu'`) или на видеокарте (`'cuda'`).
- **`requires_grad`** (требуется градиент) — `True`, если этот тензор является обучаемым параметром (весом) нейросети.

Пример с именованными аргументами (рекомендуемый стиль):

python

```
x = torch.tensor([1.0, 2.0], dtype=torch.float16, device="cuda", requires_g
```

AttributeError: 'builtin_function_or_method' object has no attribute 'shape' 
выдает ошибку строка print(torch.tensor.shape)

Эта ошибка возникает потому, что вы пытаетесь узнать форму (размер) у **самого класса** (функции) `torch.tensor`, а не у конкретного **созданного объекта (переменной)**.

В Python `torch.tensor` — это встроенная функция-конструктор. У нее нет свойства `shape`, отсюда и ошибка: `AttributeError: 'builtin_function_or_method' object has no attribute 'shape'`.
*******************
![[matrix.png]]

Чтобы занести матрицу \(B = \begin{pmatrix} 5 & 7 \\ 6 & 8 \end{pmatrix}\) с рисунка в PyTorch, нужно передать её элементы в виде двумерного списка (списка списков), где каждый внутренний список задаёт строку матрицы.

Вот **готовый код**:

python

```
import torch

# Создаем матрицу B
B = torch.tensor([[5, 7], 
                  [6, 8]])

# Проверяем результат и её размерность
print("Матрица B:\n", B)
print("Размерность (shape):", B.shape)
```
